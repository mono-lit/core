# Card docs page (VitePress)

Adds the **Card** component documentation to the VitePress docs site, following the recipe established for Checkbox, Button and Badge.

## What shipped

- Moved `demo/pages/card/css/*.html` (5 files: basic, variants, colors, states, actions) into `demo/vitepress/docs/demos/card/css/`. Removed the now-empty source directory. The `lit/` folder stays at `demo/pages/card/lit/` for the legacy standalone page.
- Authored 5 declarative Vue SFCs at `demo/vitepress/docs/demos/card/vue/` mirroring the CSS structure (4-space indent, plain prop bindings, `<br>` between examples).
- Created `demo/vitepress/docs/manifests/card.ts` with the 5 ordered demo entries.
- Created `demo/vitepress/docs/card.md` — thin: `<!-- @unocss-includes -->` + heading + one-line description + `<ComponentDocs name="card" />`.

No changes to the orchestrator (`ComponentDocs.vue`), runtime (`NativeMount.vue`, `DemoPreview.vue`), theme, or VitePress config — the framework already supports a new component as a pure data drop-in.

## Component API used

`<mono-card>` from `src/components/card/`:

- Props: `variant` (elevated/outlined/flat/tonal), `color` (primary/success/danger/warning/info/neutral/secondary), `bordered`, `hoverable`, `clickable`, `disabled`.
- Slots: `title`, `subtitle`, `icon`, `actions`, default (body).
- Event: `mno-click` (when `clickable=true` and not `disabled`).

## Notes

- The actions demo nests `<mono-button>` web components inside `<mono-card>`. Both elements are already eager-imported in `theme/index.ts`.
- The clickable card in `states.vue` dispatches `mno-click` but no Vue handler is attached (parity with the CSS source, which doesn't attach handlers in the demo file itself).
- CSS source has a benign duplicate class (`clickable clickable`) in `states.html` — preserved as-is in the move. The Vue version uses a single `clickable`.
- The standalone page at `demo/pages/card/index.html` will have broken CSS-mode source loads after the move — same trade-off already accepted for checkbox/button/badge.
