# Tabs component + docs

## Context

Second item from the `2026-05-04-template-componentization-roadmap.md` roadmap (Accordion was first). `mono-tabs` ships a horizontal tab strip — buttons + optional badges + optional SVG icons via slot. Content panes live outside the element, controlled by the consumer based on the bound `model-value`. Theme integration via shared `--theme-*` cascade.

## Files added

### Lib
- `src/components/tabs/index.ts`
- `src/components/tabs/mono-tabs.ts` — Lit element. Items array prop (`@property({ attribute: false })`), `modelValue` reflected, sizes (sm/md/lg), 6 colours, 3 variants (underline/pill/ghost), per-tab disabled, slot capture for `icon-${id}`, `mno-click` event with `{ value, oldValue, item, sourceEvent? }`.
- `src/components/tabs/tabs-types.ts` — `TabsSize`, `TabsColor`, `TabsVariant`, `TabItem`, `TabsCssClass`, `TabsClickEventDetail`, `TabsClickEvent`, `TabsProps`, `TabsEvents`.

## Patterns followed

- **Vue array-prop rule**: `:items.prop="…"` (per the codified memory entry — `items` is `attribute: false`).
- **Vue v-model rule**: `:model-value` + `@mno-click="x = $event.detail.value"` (per the codified memory entry — Vue's `runtime-dom` filters `onUpdate:*` on custom elements).
- **SVG icons via slot**: `<svg slot="icon-${id}">…</svg>` for Vue; direct `<svg>` inside `.mono-tabs-tab-icon` for CSS demos. Lucide-style outline icons with `viewBox="0 0 24 24"`, `stroke="currentColor"`, `stroke-width="2"`. Same baseline as accordion.
- **Theme integration**: every accent reads `var(--theme-X)` via `--tabs-accent` / `--tabs-accent-rgb` derived from the active color modifier. The global theme switcher recolours all tabs automatically.

## Verification

1. From `demo/vitepress/`, run the dev server and open `/tabs`.
2. All 9 demos render. Toggle Vue / CSS — both look identical.
3. Click tabs in `basic`/`badges`/`icons` — active state moves, content pane swaps.
4. The `event-log` demo shows `[mno-click] value="overview" old="klaim"` lines.
5. The `disabled` demo refuses clicks on the disabled tab.
6. Switch themes via the global picker — accent recolours through all tabs.
